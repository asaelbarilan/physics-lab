# מעבדת פיזיקה

MVP בעברית וב־RTL, React + TypeScript + Vite, עם ציור SVG. ללא backend.

## הרצה
```sh
npm install
npm run dev
npm test
npm run build
```
תוצר הפרסום הסטטי נמצא ב־dist. במהלך פיתוח Vite מדפיס את כתובת השרת.

## המתמטיקה
עבור מראה אנכית x=m, מקור S=(sx,sy) ועין E=(ex,ey), שניהם לפני המראה:
```text
I = (2m - sx, sy)
t = (m - ex) / (Ix - ex)
H = (m, ey + t * (Iy - ey))
theta_i = atan2(abs(sy - Hy), m - sx)
theta_r = atan2(abs(ey - Hy), m - ex)
```
I היא הדמות המדומה; H היא נקודת הפגיעה. מציירים S→H באדום ו־H→E בכחול. H→I הוא המשך גיאומטרי מקווקו בלבד. מציירים מסלול רק אם H נמצא בתחום המראה הסופית. הזוויות הן ביחס לאנך האופקי; בדיקות מאמתות שוויון זוויות, קולינאריות עם הדמות, שיקוף, שימור גובה ופגיעות בקצוות.

מודל לימודי: גוף סכמטי וחמש נקודות על צירו; עין נקודתית; קרן אחת מכל נקודה אל העין. הקרניים אינן מתפצלות. גובה המראה משתנה סביב מרכז קבוע בגובה 105 ס״מ. בחירת נקודה מדגישה את הקרן שלה ואת הזוויות שלה. במצב שלבים השכבות מופיעות לפי סדר לימודי; בחקירה חופשית אפשר לשלוט בכל שכבה בנפרד.

## הרחבה
להוסיף תיקייה עצמאית תחת simulations לכל סימולציה ולרשום אותה בקטלוג. הצעדים הבאים: תרגילי שדה ראייה ומרחקים, גרירה ישירה ומצב הקרנה, החזרה מפוזרת ושתי מראות; בהמשך שבירה, עדשות ופריזמה, ומודולים למכניקה, אנרגיה וחשמל.
דרישת סביבה: Node.js 22.12 ומעלה. ממשק WebMCP אופציונלי נוסף; אימותו בדפדפן תומך לא בוצע.

גרירה: אפשר לגרור את הגוף או את הדמות המדומה מעלה ומטה כדי לשנות את גובה העצם, בטווח 80–200 ס״מ. נתמכים עכבר, מגע ועט, עם לכידת מצביע והמרה מדויקת של קואורדינטות המסך ל־SVG. כאשר הגוף במיקוד מקלדת, חצים למעלה/למטה משנים את הגובה.

### הנחות מדעיות
היווצרות כוכב: ענן אחיד, גז איזותרמי בתחילת הדרך (10 K), מסה ממוצעת לחלקיק 2.33 מסות פרוטון. מחושבים M_J = π^(5/2) c_s³ / (6 G^(3/2) √ρ) ו־t_ff = √(3π/(32Gρ)). האנימציה אינה פותרת הידרודינמיקה, טמפרטורת ליבה או משך ההגעה להיתוך; מצוין בממשק שהיא רצף לימודי. קריסה עשויה ליצור כמה כוכבים במציאות.
חור שחור: גוף כדורי, לא מסתובב וללא מטען. R_s = 2GM/c². הכיווץ הוא ניסוי מחשבתי, לא פתרון קריסת ליבה ולא הזמן הנצפה מבחוץ. פנים האופק אינו מוצג כחומר נראה.

### הרחבת שיעור ג׳ינס ורדיוסים כוכביים
JeansLesson.tsx מציג את תנאי M > M_J, נוסחת מסת ג׳ינס, המרת צפיפות מספרית לצפיפות מסה ונוסחה מקורבת במסות שמש. התרגיל שומר צילום מצב של המסה והצפיפות; יעד הצפיפות גדול או קטן פי 4 כדי להישאר בטווח הבקרות. נדרשים חישוב (עד 2% סטייה), תחזית נכונה, ובקרות תואמות (עד 3% בצפיפות, מסה ללא שינוי) עם מצב קריסה תואם. כפתור מפורש יוצר תרגיל חדש.
רדיוס הגוף בחור השחור: 1 ק״מ עד 1,000 רדיוסי שמש, בקרה לוגריתמית וקיצורי דרך ל־0.1, 1, 10, 100, 1000 רדיוסי שמש. ברירת המחדל רדיוס שמש ומסה של 10 מסות שמש, כהשוואת גדלים בלבד. הסולם מתקרב אוטומטית; אופק קטן מפיקסל מסומן בטקסט ולא מוגדל באופן מטעה.
רדיוס שמש נומינלי 695,700 ק״מ לפי [IAU 2015 B3](https://www.iau.org/common/Uploaded%20files/IAUGA2015-Resolution-B3-recommended-nominal-conversion.pdf).
אימות: 28 בדיקות יחידה; בדיקות דפדפן לחישוב שגוי, חישוב נכון ללא שינוי בקרה, השלמת הניסוי, שינוי מסה, יעד צפיפות בקצה הטווח, גדלים כוכביים, סף האופק, גרירה, מקלדת ותצוגת מובייל.


## דיאגרמת H–R
המודול זמין ב־#hr, מתוך קטלוג האסטרונומיה. HRDiagram.tsx מציג שני צירים לוגריתמיים, טמפרטורה עולה שמאלה והארה עולה למעלה. גרירת הכוכב עובדת בעכבר/מגע/עט עם לכידת מצביע, ובמקלדת עם חצים ו־Shift. בקרות טמפרטורה, הארה ורדיוס מסונכרנות לפי חוק סטפן–בולצמן היחסי לשמש (T☉ = 5772 K). טמפרטורה משתנה בהארה קבועה; רדיוס משתנה בטמפרטורה קבועה.
hrPhysics.ts מפריד את החישוב והמרת הקואורדינטות מהציור; 9 בדיקות חדשות מכסות נרמול, חוקי קנה מידה, היפוך משוואות, כיווני הצירים, גבולות ותרגיל. 37 בדיקות בסך הכול.
דוגמאות לסדרה הראשית, ענק אדום וננס לבן הן סכמטיות. אין הסקת מסה/גיל/מסלול חיים מנקודת גרירה ואין קטלוג תצפיות. צבע הכוכב מקורב; הגודל באיור דחוס ומסומן כך. קווי רדיוס קבוע מחושבים מהנוסחה.
תרגיל חישובי שומר תנאי התחלה, מבקש שינוי הארה פי 4 בטמפרטורה קבועה, ובודק תשובה וגם את מיקום הסימולציה. נוספו 3 שאלות עם משוב.
נבדק מדמה קיים של [אוניברסיטת נברסקה](https://astro.unl.edu/smartphone/hrdiagram/); המודול נכתב עצמאית כדי לשלב RTL, בקרות משותפות ותרגיל תלוי מצב. לא הועתק קוד. [OpenStax](https://openstax.org/books/astronomy-2e/pages/18-4-the-h-r-diagram) משמש מקור לכיווני הצירים ולפירוש אזורי הכוכבים.
